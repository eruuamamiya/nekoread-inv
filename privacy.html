Kebijakan Privasi

Terakhir diperbarui: 2 November 2026

Ringkasnya

Kami hanya memakai data dasar dari Discord untuk menjalankan fitur. Data tidak dijual dan tidak dipakai untuk iklan.

Data yang kami terima

  • Dari Discord: ID, nama pengguna, dan avatar kamu, serta ID server dan voice channel saat Activity dibuka. Data ini dipakai untuk menampilkan peserta yang sedang membaca.
  • Linked Roles (opsional): kalau kamu menghubungkan akun lewat Linked Roles, kami menerima token akses Discord dengan izin role_connections.write dan identify.
  • Data teknis: log server dasar seperti alamat IP dan waktu akses, untuk keamanan dan perbaikan masalah.

Untuk apa data dipakai

  • Menjalankan Activity dan bot.
  • Memperbarui status Linked Roles milik kamu di Discord.
  • Menjaga keamanan dan memperbaiki gangguan.

Yang tidak kami lakukan

Kami tidak menjual data kamu, tidak memakainya untuk iklan, dan tidak membagikannya ke pihak lain, kecuali diwajibkan hukum. Kami tidak membaca pesan pribadi kamu.

Penyimpanan

Token Linked Roles hanya dipakai sekali saat kamu memverifikasi dan tidak disimpan setelahnya. Log server disimpan seperlunya lalu dihapus berkala.

Layanan pihak ketiga

Discord memproses data kamu sesuai Kebijakan Privasi Discord. Konten komik berasal dari sumber pihak ketiga yang punya kebijakan sendiri.

Hak kamu

Kamu bisa mencabut akses kapan saja lewat Discord (Pengaturan Pengguna → Aplikasi Resmi) atau meminta penghapusan data kepada kami.
